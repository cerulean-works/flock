# Scaling-law pilot sweeps

The sweep configs, Slurm launchers and helper scripts used for the 100M / 200M / 400M / 750M
scaling-law pilot on NCHC nano4 (Nov 2026), kept verbatim as they ran. Paths point at the
cluster's `/work/u4982363` and `~/experiments` layout.

- `llama{100m,200m,400m}-*.yaml`: Muon LR x AdamW LR x batch (x beta2) sweeps at 20 (and 40)
  tokens per parameter; `llama200m-8b-*`: top runs branched to 8B tokens.
- `llama750m-*.yaml`: 750M phase 1 (Muon LR x batch, with 7.5B-token decay branches) and phase 2
  (`llama750m-p2-1m`: AdamW LR x beta2 at 1M / Muon 8e-3). Generated by `make_750m.py`.
- `wsd-*.yaml`: 100M/200M WSD long runs, their decay ladders, and the 400M production run.
- `*.sbatch`: launchers (`multi_launch*.sbatch` packs several sweeps into one allocation).
- `*_watcher.py`: systemd-run watchers that submit decay jobs / resubmit sweeps.

Model sizes use the `llama3.2-{100m,200m,400m,750m}` presets in
`flock/training/experiments/scaling_law/config.py`; the configs here spell the same shapes as
`overrides` on `llama3.2-200m`.

- [Sign in and manage access](../../docs/source/cli/sign-in.md)
- [Use S3 storage](../../docs/source/cli/s3-access.md), including ephemeral and persistent keys
- [Use storage from Python](../../docs/source/cli/use-python-storage.md), including Lance datasets
- [Authenticate an unattended job](../../docs/source/cli/authenticate-jobs.md)

The [command reference](../../docs/source/cli/commands.md), [credential resolution and Python API](../../docs/source/cli/credentials.md), and [Python S3 API](../../docs/source/cli/python-s3.md) cover complete interfaces and edge cases.
